## 📋 Como Contribuir com um Novo Estudo de Caso

Se você deseja adicionar um novo caso de estudo, siga uma estrutura analítica consistente:

1. **Contexto:** Defina o sistema, ambiente, pressões operacionais e um resumo do evento.
2. **Análise Sistêmica:** Explore como o sistema lidou com a variabilidade, se houve migração silenciosa para limites perigosos e como as barreiras de defesa se comportaram.
3. **Lições Aprendidas:** Destaque os aprendizados focados em melhoria sistêmica e o contraste entre o "trabalho real" e o "trabalho imaginado".

Sinta-se à vontade para abrir uma *pull request* adicionando novos cenários.
